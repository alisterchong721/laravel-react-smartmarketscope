# MLR Event Study

Status: `DESCRIPTIVE_TECHNICAL_ONLY`

The study registered 89 D1+H4 technical event windows across 2017-2026. It
measured component and midpoint-reach frequency only. No forward return, MFE,
MAE, stop/target outcome, PnL, cost, hit rate, or significance statistic was
computed.

This is not a macro event study because no certified macro observation was
eligible. It cannot establish direction, incremental macro contribution, or
strategy edge.
